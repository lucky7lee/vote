# 실시간 설문조사 & 투표 웹앱 (스마트폰 / Windows 최적화)

스마트폰 모바일 화면과 Windows PC 브라우저에 모두 최적화된 반응형 여론조사 및 투표 웹 애플리케이션입니다.

## 주요 기능

1. **첫 메뉴**: 오직 **"작성하기"** 메뉴 아이콘 하나만 깔끔하게 표시됩니다.
2. **암호 인증**: `작성하기` 아이콘을 누르면 암호 입력 창이 뜨며, **`77777`**을 입력해야 설문/투표 작성 화면으로 진입합니다.
3. **직관적인 질문 및 보기 추가**:
   - 처음 작성 화면에는 **첫 번째 질문 칸**과 **첫 번째 보기 칸** 딱 2개만 보입니다.
   - 질문 입력 칸 바로 옆의 작은 **`+`** 버튼을 누르면 다음 질문을 작성할 수 있습니다.
   - 보기 입력 칸 바로 옆의 작은 **`+`** 버튼을 누르면 다음 보기를 추가할 수 있습니다.
4. **설문조사 사이트 링크 생성 (GitHub Pages 주소 자동 연동)**:
   - 하단의 **작성완료** 버튼을 누르면 누구나 접속하여 설문/투표에 참여할 수 있는 고유 링크(`https://<아이디>.github.io/<저장소명>/?poll=...`)가 즉시 생성됩니다.
5. **실시간 투표 및 상세 결과보기**:
   - 일반 사용자는 공유받은 링크를 클릭해 바로 투표를 진행할 수 있습니다.
   - 제일 아래의 **결과보기** 버튼을 누르면 각 질문 항목별 **투표수(표)**, **득표율(%)**, **최다 득표 1위 표시**, **비율 막대그래프**를 실시간으로 확인할 수 있습니다.

## GitHub 업로드 및 온라인 링크(GitHub Pages) 생성 방법

1. [GitHub 새 저장소 만들기](https://github.com/new) 페이지에 접속하여 새 저장소(예: `vote`)를 **Public**으로 생성합니다.
2. 현재 폴더(`d:\vote`)에서 터미널(PowerShell)을 열고 아래 명령어를 실행해 업로드합니다 (`<본인깃허브아이디>` 부분만 본인 아이디로 변경):

```powershell
cd d:\vote
git remote add origin https://github.com/<본인깃허브아이디>/vote.git
git push -u origin main
```

3. GitHub 저장소 상단 메뉴에서 **Settings** -> 왼쪽 메뉴의 **Pages**로 이동합니다.
4. **Build and deployment** 아래의 **Source**를 `Deploy from a branch` (Branch: `main` / `/(root)`) 또는 `GitHub Actions`로 선택 후 저장하면 약 1분 뒤 아래와 같은 온라인 주소가 생성됩니다:
   - `https://<본인깃허브아이디>.github.io/vote/`
5. 생성된 온라인 주소로 접속하여 설문을 만들고 **작성완료**를 누르면, 자동으로 해당 GitHub 주소(`https://<본인깃허브아이디>.github.io/vote/?poll=...`)를 사용하는 투표 사이트 링크가 만들어집니다.
